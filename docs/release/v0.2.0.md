# Unified AI Governance & Security v0.2.0

v0.2 completes governance and operational workflows in the existing independent
FastAPI/Next.js application. The original v0.1 commit remains preserved.

- Governance records link rationale, owners, deadlines and evidence to systems,
  risks and three framework assessments. Assessment history/export and completion
  controls preserve changes.
- Policies have version history, optimistic edits and rollback. Runtime decisions
  create privacy-safe events and an explicit human-review queue.
- Membership role changes/removal, last-administrator protection and password
  changes with session revocation are supported.
- Tenant integration enablement/health, durable job status/cancellation/retry,
  PostgreSQL idempotency and Redis recovery are verified.
- Actual OPA 1.22.4 and optional Presidio 2.2.366 HTTP services are tested.
  Presidio uses a pinned, checksum-verified English model and cannot restore
  prior redactions through malformed anonymizer responses.
- Browser contrast, exact title display and assessment-dialog race defects were
  fixed. Runtime image package-manager and zlib findings were remediated.

Verification: 55 backend tests with genuine service/CLI/package/crypto checks;
7 frontend unit tests; type checking and production build; 9 Docker-backed
browser tests; 13 PostgreSQL migration/RLS checks; concurrent tenant/idempotency,
rate-limit, persistence and worker-recovery checks. See VERIFICATION.md.

Measured full HTTP native + Presidio + OPA p99: 85.8 ms short safe, 91.6 ms short
PII, 879.9 ms near-limit (100 samples each). These local loopback results include
auth, Redis rate limiting, PostgreSQL RLS/event/audit persistence; they exclude
public TLS/WAN/cloud overhead. There is no sub-50 ms end-to-end guarantee.

Upgrade: back up PostgreSQL and signing material, build the pinned images, run
migration 0002 and retain existing volumes. Keep Presidio/signing overlays in
subsequent Compose commands. See DEPLOYMENT.md for platform-specific setup.

Limitations: public source release, not hosted production certification.
Unfixed Debian image advisories and OPA's unused HTML-parser path are disclosed
with mitigations/expiry in SECURITY_REVIEW.md. No external penetration test,
cloud deployment, restore drill, comprehensive PII/model protection, automatic
retention/notifications, SSO, Cosign, Envoy or deferred model execution is claimed.
The 25-entry register has five executable, five reference, eleven deferred and
four licence-restricted entries. VerifyWise VCEL, OpenComplAI AGPL, missing
toolkit licences and model-specific terms prevent silent inclusion.
